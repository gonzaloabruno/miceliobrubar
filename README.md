# Micelio Brubar

Tienda online de Micelio Brubar: micelio, kits de autocultivo, jeringas, placas y sustratos para cultivar hongos.

- `index.html`: la tienda completa (catálogo, carrito y pago por transferencia).
- Los productos, precios y datos de pago están en el bloque `catalog-data` dentro de `index.html`.
- Se publica con GitHub Pages desde la rama `main`.
